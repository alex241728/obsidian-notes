# 1. Installation (via `rustup`)

## Linux / macOS
Run the following command in your terminal:
```bash
curl --proto '=https' --tlsv1.2 [https://sh.rustup.rs](https://sh.rustup.rs) -sSf | sh
```

> [!warning] Dependency: Linker & C Compiler
> Rust requires a linker to produce executables. If linker errors occur:
> - **macOS**: `xcode-select --install`
> - **Ubuntu/Debian**: `sudo apt install build-essential`
> - **Other Linux**: Install `gcc` or `clang` via your package manager

## Windows
1. Download and run the installer from [rust-lang.org/tools/install](https://www.rust-lang.org/tools/install).
2. Install the **Visual Studio C++ Build Tools** when prompted to provide the necessary linker and native libraries.

# 2. Verification & Troubleshooting

## Check Installation
```bash
rustc --version
# Expected output: rustc x.y.z (abcabcabc yyyy-mm-dd)
```

## Path Verification
If `rustc` is unrecognized, ensure the binary directory is in your `PATH`:
- **Linux / macOS**: `echo $PATH`
- **Windows CMD**: `echo %PATH%`
- **PowerShell**: `echo $env:Path`

# 4. Offline Dependency Caching (Book Walkthrough)

To cache external dependencies used in the book for offline work:

```bash
cargo new get-dependencies
cd get-dependencies
cargo add rand@0.8.5 trpl@0.2.0
```

> [!tip] Note
> Delete the `get-dependencies` folder once caching finishes. You can subsequently pass `--offline` to `cargo` commands to build without internet access.
