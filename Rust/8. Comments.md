# 1. Line Comments (`//`)

In Rust, the idiomatic comment style begins with two forward slashes (`//`). The compiler completely ignores everything from `//` to the end of the line.

* **Single-line & Multi-line**: Multi-line comments are conventionally written by repeating `//` on each successive line rather than using block comment syntax.
  ```rust
  // This is a multi-line explanation.
  // Each line begins with double slashes.
  // Rust idioms prefer this style.
  ```
* **Placement Conventions**:
  * **Above the code (Recommended)**: Placed on a dedicated line immediately preceding the target code.
    ```rust
    // I'm feeling lucky today
    let lucky_number = 7;
    ```
  * **Trailing / End-of-line**: Placed after code on the same line.
    ```rust
    let lucky_number = 7; // I'm feeling lucky today
    ```

---

# 2. Distinct Comment Types

* **Standard Comments (`//`)**: Intended for source code readers and implementation notes; completely ignored by the compiler.
* **Doc Comments (`///` or `//!`)**: Document public APIs and support Markdown formatting; parsed by `cargo doc` to generate HTML documentation.
