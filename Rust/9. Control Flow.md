# 1. `if` Expressions

* **Strict Boolean Conditions**: The condition **must** evaluate to a `bool`. Rust does not coerce non-Boolean types (no truthy/falsy values like `0` or `None`). Passing an integer triggers compile error `E0308`.
* **Branch Arms**: Code blocks tied to conditions are known as arms. Multiple branches use `else if`, though large chains are idiomatic candidates for refactoring into `match`.

## `if` as an Expression in `let` Bindings
Because `if` is an expression, its evaluated value can be assigned directly to a variable:

```rust
let condition = true;
let number = if condition { 5 } else { 6 };
```

> [!danger] Type Compatibility Requirement (`E0308`)
> All arms of an `if` expression **must evaluate to the same type**.
> ```rust
> let number = if condition { 5 } else { "six" }; // ERROR: incompatible types (`i32` vs `&str`)
> ```
> Variables must have a single, statically known type determined at compile time.

# 2. Repetition with `loop`

The `loop` keyword declares an unconditional infinite loop terminated via `break` or process interruption (`Ctrl-C`).

## Returning Values from `loop`
Loops can evaluate to a value by passing an expression after the `break` keyword:

```rust
let mut counter = 0;

let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20 out of the loop expression
    }
}; // Statement ends with a semicolon
```

## Loop Labels (`'label`)
By default, `break` and `continue` apply strictly to the innermost loop. Prefixed loop labels (prefixed with a single quote `'`) disambiguate nested control flow:

```rust
'counting_up: loop {
    let mut remaining = 10;
    loop {
        if remaining == 9 {
            break; // Exits innermost loop
        }
        if count == 2 {
            break 'counting_up; // Exits outer loop labeled 'counting_up
        }
        remaining -= 1;
    }
    count += 1;
}
```

# 3. Conditional Loops with `while`

Executes its body block while a given condition remains `true`:

```rust
let mut number = 3;
while number != 0 {
    println!("{number}!");
    number -= 1;
}
```

# 4. Iterating Collections with `for`

The `for` construct iterates safely and idiomatically over collections and ranges.

```rust
let a = [10, 20, 30, 40, 50];

// Idiomatic collection iteration
for element in a {
    println!("the value is: {element}");
}

// Numerical ranges with .rev()
for number in (1..4).rev() { // Range 1..4 excludes upper bound (1, 2, 3)
    println!("{number}!");
}
```

| Loop Construct                             | Usability                                    | Safety & Performance                                                                                                 |
| :----------------------------------------- | :------------------------------------------- | :------------------------------------------------------------------------------------------------------------------- |
| **`while` Indexing** (`while index < len`) | Requires manual index tracking and mutation. | **Error-prone**: Risk of out-of-bounds panics if bounds change. Slower due to per-iteration runtime bounds checking. |
| **`for` In Loop** (`for x in collection`)  | Concise, declarative syntax.                 | **Safe & Efficient**: Eliminates out-of-bounds bugs and compiler skips repetitive runtime boundary checks.           |
